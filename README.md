# Module 4 feature

This is the standalone feature delivery. It contains only two application folders:

- `backend` — API, audit trail, company management, exports, and notifications
- `frontend` — Module 4 React user interface

Run the backend in one terminal:

```powershell
cd backend
npm install
npm run dev
```

Run the frontend in another terminal:

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. The feature uses a built-in development super-admin user, so no login is required.
