# Module 2: Inventory & Manufacturing Operations

A high-performance inventory and production tracking engine for the INtrack SaaS platform. Built with React, Vite, Tailwind CSS (dark-forest glassmorphism aesthetic), Node.js, Express, and MongoDB/Mongoose.

---

## Features & Core Deliverables

* **Supplier Directory:** Manage vendor partners with 5-star reliability ratings, lead-time tracking, and instant vendor registration.
* **Inbound PO Ingestion:** Log and verify inbound purchase order delivery slips and weighbridge receipts with real-time warehouse balance increments.
* **Dynamic BOM Builder:** Configure multi-tier Bill of Materials recipes supporting decimal/fractional unit consumption.
* **Manufacturing Run Modal:** Execute batch production with real-time stock deduction preview and atomic balance decrementing.
* **Automated Low-Stock Alerts:** Safety stock threshold monitoring with interactive visual warnings.

---

## Tech Stack

* **Frontend:** React 18, Vite 5, Tailwind CSS, Lucide React
* **Backend:** Node.js, Express.js, Mongoose, MongoDB
* **Theme:** Leafora Deep-Forest Glassmorphism (`#06130e` background with emerald glass accents)
