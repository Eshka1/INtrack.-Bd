# Frontend Integration
Install `axios i18next react-i18next`. Import `./module4/i18n` once near the React app entry. Then import and render `Module4Dashboard`. If React Router is used: `<Route path="/module4" element={<Module4Dashboard />} />`. No frontend unit tests are included because backend-only unit testing was requested.


## Neomorphism theme

`Module4Dashboard.jsx` imports `module4-neomorphism.css` directly, so no extra theme package is required. The visual style is a dark emerald neomorphic/glass-inspired UI based on the supplied reference image.
